Security Policy
Security Model
The Bytebeat x Game of Life Sonifier operates entirely on the client side inside the user's web browser context.
Sandboxed Execution: Math expressions are dynamically parsed as pure numeric functions. No network calls, disk access, or DOM manipulations are accessible to evaluated expressions.
Zero Telemetry: No user data, sound byte streams, or system metrics are ever logged or transmitted off-device.
Dependencies: All external UI dependencies (Tailwind CSS and Lucide Icons) are fetched over secure HTTPS endpoints with intact integrity parameters.
Reporting Vulnerabilities
If you discover any security issue or vulnerability within this application, please report it privately:
Open a confidential security advisory directly on GitHub via [j-mosij/bytebeat-game-of-life-sonifier Security Tab].
Alternatively, open an issue labeled security-audit.
Reports will be reviewed and responded to within 48 hours.
